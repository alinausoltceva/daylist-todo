# Лабораторная работа 2: To-Do List

Daylist — веб-приложение для управления повседневными задачами. Пользователь может создавать задачи, указывать сроки выполнения, редактировать и удалять их, отмечать выполненные задачи, искать и фильтровать список, а также менять порядок задач с помощью drag-and-drop.

## О проекте

Создано веб-приложение для ведения списка задач с возможностью сохранять данные между сеансами работы.

В приложении представлены:

- форма добавления новых задач;
- список задач с указанием названия и даты выполнения;
- возможность редактировать и удалять задачи;
- отметка задач как выполненных;
- поиск и фильтрация задач;
- сортировка по дате выполнения;
- перетаскивание задач для изменения их порядка;
- счётчики общего количества и выполненных задач.

## Управление задачами

Пользователь может создавать задачи, указывая название и дату выполнения. Дата является необязательным полем. Каждая задача отображается в отдельной карточке. Для неё доступны следующие действия:

- редактирование названия и даты;
- удаление из списка;
- отметка как выполненной или активной.

При выполнении задачи её визуальное оформление изменяется: название становится зачёркнутым, а карточка получает соответствующий стиль.

Задачи с истёкшим сроком выполнения дополнительно выделяются в списке. Текущая дата не считается просроченной, а выполненные задачи не помечаются как просроченные.

## Поиск, фильтрация и сортировка

Для удобства работы со списком реализованы поиск, фильтрация и сортировка задач.

**Поиск** позволяет находить задачи по названию. Результаты обновляются по мере ввода текста.

**Фильтрация** разделяет задачи на три категории: все задачи, активные и выполненные. Поиск и фильтрация могут использоваться одновременно.

**Сортировка** позволяет упорядочить задачи по дате выполнения — по возрастанию или убыванию. При этом задачи без указанного срока располагаются в конце списка.

## Изменение порядка задач

Реализована возможность менять расположение задач с помощью drag-and-drop. Пользователь может перетаскивать карточки и устанавливать их в нужном порядке. Изменение порядка сохраняется и восстанавливается после перезагрузки страницы. Перетаскивание доступно при отображении полного списка без активного поиска, фильтрации и сортировки.

## Сохранение данных

Для хранения задач используется `localStorage`. Данные сохраняются в формате JSON. При загрузке страницы приложение восстанавливает ранее созданные задачи, включая их названия, даты выполнения, статусы и пользовательский порядок. Таким образом, задачи не исчезают после закрытия или обновления страницы.

## Адаптивный интерфейс

Приложение адаптировано для различных размеров экрана. Поддерживаются:

- компьютеры и ноутбуки;
- планшеты;
- мобильные устройства.

Расположение элементов, карточек задач, кнопок и элементов управления изменяется в зависимости от ширины экрана.

## Технологии

Проект реализован с использованием HTML5, CSS3 и чистого JavaScript без сторонних библиотек и фреймворков. Для создания структуры страницы используется DOM API. Все элементы интерфейса формируются динамически с помощью JavaScript, а HTML-файл содержит только базовый каркас документа и подключение скрипта.

Для хранения данных используется `localStorage`, для изменения порядка задач — HTML Drag and Drop API, для построения адаптивного интерфейса — Flexbox и CSS.
